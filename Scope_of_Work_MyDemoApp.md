## Introduction:

This is a sample Scope of Work document created for illustrative and portfolio demonstration purposes only. The content does not relate to any real project or agreement. This document can be tailored to meet customer-specific requirements.

## Project Overview: 

Sauce Labs MY DEMO APP is a publicly available android app on GitHub and is used in this portfolio project to demonstrate software testing skills. The application contains various categories for testing purposes and includes features that simulate real-world e-commerce scenarios. 
For this project, the e-commerce category will be used to demonstrate functional and UI testing.

## Test Approach: 

As no formal requirements specification document is available for this demonstration project, exploratory testing techniques will be used to identify and validate issues within the defined scope. 

Key user journeys and e-commerce features will be explored and validated from a functional and UI perspective.

## In-Scope:

Functional and UI testing will be performed for the following features: 
1.	Login  
2.	Product Catalog 
3.	Add to Cart   
4.	Place Order  
5.	End-to-End purchase flow   
A minimum of four bug reports will be created to demonstrate different severity levels. Each bug report will include, where applicable: 
•	Detailed steps to reproduce  
•	Expected and actual results  
•	Screenshots and/or screen recordings    
•	Crash logs, if applicable
    
## Test Environment:  

	   Android device
        Device: Samsung Galaxy S22
        OS: Android 16
## Deliverables:
•	Scope of Work (SOW) document
•	A set of bug reports (minimum of 4) 
## Out of Scope:
Any items, features, or activities not explicitly identified in the In-scope section are considered out of scope for this demonstration project.
## Assumptions:
•	The application will remain accessible and testable throughout the testing activities.
•	No major application changes will be introduced during testing activities.
•	Required access to the application will be available throughout the testing
•	The defined testing environment will be available for testing activities
## Acceptance Criteria:
Deliverables will be considered complete upon submission of the bug reports that meet the defined scope.
